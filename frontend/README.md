# IvRaws — Frontend

React + Vite + TypeScript + Tailwind v4 storefront for IvRaws, an Indian streetwear brand.

## Development

```bash
npm install
npm run dev
```

Requires the backend API running (see repo root) and `VITE_API_URL` set in `.env` — see `.env.example`.

## Scripts

- `npm run dev` — start the Vite dev server (port 5180)
- `npm run build` — typecheck and build for production
- `npm run lint` — run Oxlint
- `npm run preview` — preview the production build locally
